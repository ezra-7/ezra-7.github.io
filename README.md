# Ezra Admasu Portfolio

Blueprint-based GitHub Pages portfolio with:
- Responsive dark IT/developer design
- Hero, About, Skills, Projects, Education, and Contact sections
- IT-themed background image
- Web3Forms AJAX contact form
- In-page success message: "Message sent successfully! I'll get back to you soon."

## Install on GitHub Pages

1. Replace your existing `index.html`, `style.css`, and `script.js` with these files.
2. Upload the `assets` folder too.
3. In `index.html`, find:
   `YOUR_ACCESS_KEY_HERE`
4. Replace it with the Web3Forms access key you already created.
5. Commit the changes.
6. Wait for GitHub Pages to redeploy.

The contact form uses the client-side Web3Forms API, so no separate backend is required.
